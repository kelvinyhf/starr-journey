# Starr Journey
A casual web game about Starr dodging obstacles, built with KAPLAY.

## How to Play
1. Swipe your mouse or drag your thumb to control Starr ⭐️
2. Dodge obstacles, collect coins, try to go as far as you as can 🚀
3. That's it!

## Installation
No setup needed, simply click [this link](https://starrjourney.pages.dev) and enjoy 😀
